## 1. Philosophy: Memes as Culture, Not Ads

### 1.1 The Anti-Marketing Marketing Approach

> "The moment a meme feels like marketing, it dies."

Gen Z has the most sophisticated advertising detection in history. They've grown up bombarded with sponsored content and have developed immunity. The only way to reach them authentically is to *not* try to reach them—to create genuine value and culture that spreads because people *want* to share it.

**What Doesn't Work:**
- Forced memes (created in boardrooms)
- Fellow kids energy (brands trying too hard)
- Hijacking trends (slapping logo on existing formats)
- Engagement bait (obvious manipulation)

**What Works:**
- Genuine community moments (that happen to spread)
- Self-deprecating humor (we laugh at ourselves)
- Inside jokes (exclusivity breeds desire)
- Participatory culture (people create, we amplify)

## 2. The Core Memes

### 2.1 "Are Y'all Getting on Roanoke TN?"

**Origin:** Organic Twitter/X post from early player, mimicking "are we going out tonight?" energy

**Format:**
- Screenshot of group chat or DM
- Someone asking if friends are playing
- Implication: this is the move, this is what cool people do

**Why It Works:**
- Social proof without being explicit
- Creates FOMO naturally
- Positions Roanoke as the default
- Easy to participate (just screenshot your chat)

**Variations:**
```
"are yall getting on roanoke tn or are we boring"
"me at 2am: just one more hour"
"my sleep schedule when roanoke drops new content"
"every night: should I sleep? roanoke:"
```

**Amplification Strategy:**
- Retweet organic versions (never create)
- Feature in community spotlights
- Make it a Discord reaction emote
- Never, ever explain it

### 2.2 "CROATOAN"

**Origin:** The actual historical mystery (carved in tree when colony vanished)

**In-Game:** Mysterious events, unexplained occurrences

**Meme Usage:**
- Something weird happens → "CROATOAN"
- Unexplained bug → "CROATOAN"
- Someone disappears → "CROATOAN"
- Any mystery → "CROATOAN"

**Format Examples:**
```
*character clips through floor*
Player: "CROATOAN"

My inventory after the update: [empty]
Me: "CROATOAN"

POV: Your friend logged off without saying goodbye
[CROATOAN intensifies]
```

**Why It Works:**
- Deep lore connection
- Single word = instant recognition
- Versatile application
- Historical mystery adds gravitas

### 2.3 "The Trees Are Watching"

**Origin:** Early AI bug where tree entities tracked player position unexpectedly

**Evolution:** Became symbol of game's living world / paranoid humor

**Format:**
```
Me: *trying to sneak*
The trees: 👁️👁️

"Don't worry, no one's around"
The trees: [screenshot of many trees]

POV: You're being hunted but there's no animals nearby
[forest screenshot]
```

**Why It Works:**
- Based on real game moment
- Paranoia is universally relatable
- Environmental awareness theme
- Visual meme potential

### 2.4 "Just One More [X]"

**Origin:** Addictive gameplay loop (like Civilization's "one more turn")

**Format:**
```
Me at 11pm: just one more tree
Me at 4am: [elaborate base]

"I'll log off after I finish this wall"
*6 hours later*

My productivity: 📉
My virtual settlement: 📈
```

**Why It Works:**
- Self-deprecating humor
- Relatable addiction narrative
- Shows game is compelling
- Easy template for variations

### 2.5 Emergent Memes (Examples of What We Watch For)

| Pattern | Example | Action |
|---------|---------|--------|
| Unexpected gameplay moment | Animal glitch goes viral | Acknowledge humorously |
| Community in-joke forms | Nickname for location | Adopt in official communications |
| Cross-platform trend | Sound/format that fits | Monitor, don't force |
| Player achievement | First to discover secret | Celebrate and amplify |

## 3. Platform-Specific Strategy

### 3.1 TikTok (Primary Gen Z Channel)

**Content Types:**

| Type | Description | Frequency |
|------|-------------|-----------|
| Gameplay Clips | 15-30 sec highlights | Daily |
| POV Format | First-person storytelling | 3x/week |
| Trends | Participate when authentic | As relevant |
| Behind-the-Scenes | Dev life, office, builds | Weekly |
| Duets/Stitches | React to community content | 2x/week |

**Voice & Tone:**
- Self-aware, slightly chaotic
- Never try hard
- Embrace imperfection
- React, don't create trends

**Sound Strategy:**
- Use trending sounds when they fit naturally
- Create original sounds from game audio
- Don't force game audio onto trends

**Example TikToks:**

*Good:*
```
[Trending sound about making bad decisions]
*walks into dark cave with no supplies*
Caption: "worth it for the vibes"
```

*Bad:*
```
"Check out the NEW ROANOKE UPDATE!
Features include:
- New biome
- New enemies
- 50% off!"
```

### 3.2 Twitter/X

**Content Strategy:**

| Day | Content Type | Examples |
|-----|--------------|----------|
| Mon | Weekly meme | Retweet best community content |
| Tue | Dev insight | Casual behind-the-scenes |
| Wed | Community highlight | Feature player creation |
| Thu | Engagement | Reply, quote tweet, interact |
| Fri | Anticipation | Weekend vibes, "getting on tn?" |
| Sat | Gameplay | Active session documentation |
| Sun | Lore/story | Mystery hints, theories |

**Engagement Rules:**
- Reply within 1 hour to all @mentions
- Quote tweet > retweet (adds personality)
- Embrace ratio when warranted
- Self-deprecate freely
- Never delete unless egregious

**Thread Strategy:**
- Lore threads (deep mystery exploration)
- Dev threads (how things work)
- Community threads (spotlight series)
- Never "1/47" sales threads

### 3.3 Instagram

**Feed:**
- High-quality screenshots
- Art direction consistent
- Caption as conversation starter
- 2-3 posts per week

**Stories:**
- Daily activity
- Polls, questions, engagement
- Behind-the-scenes
- Community reposts

**Reels:**
- TikTok cross-post (optimized)
- Platform-specific when needed
- Less chaotic than TikTok

### 3.4 Discord

**Meme Channels:**
- #memes (general)
- #screenshots (gameplay moments)
- #fan-art (creative works)
- #cursed-content (weird finds)

**Emote Strategy:**
- Community-designed emotes
- Meme-origin emotes (CROATOAN)
- Reaction emotes for common responses
- Limited edition event emotes

**Bot Integration:**
- !croatoan command (random mystery)
- Level system with meme titles
- Community vote for weekly meme

### 3.5 Reddit

**Subreddit Strategy (r/RoanokeGame):**

- Moderator presence (light touch)
- Official flair for staff posts
- AMAs (not too frequent)
- Never suppress criticism
- Celebrate organic memes

**Other Subreddits:**
- r/gaming: Major announcements only
- r/indiegaming: Dev journey content
- r/[competitors]: Never astroturf
- r/memes: Only if organic

## 5. The "Don't" List

### 5.1 Never Do These Things

**Never Force a Meme:**
```
BAD: "Let's make 'Roanoke Moment' happen"
     [Creates posts using the phrase]
     [Asks influencers to use it]
     [Buys promoted tweets]

GOOD: "Hey, community seems to call weird glitches
       'getting CROATOAN'd'. That's cool."
     [Uses it when natural in our posts]
     [Never makes it official]
```

**Never Explain the Joke:**
```
BAD: "CROATOAN means the mystery of the
     Lost Colony, which ties into our game's
     theme of exploration and discovery!"

GOOD: "CROATOAN"
```

**Never Over-Produce:**
```
BAD: [Professional video, studio quality,
      obviously expensive production]
     "Hello fellow gamers!"

GOOD: [Shaky phone footage, dev at desk]
     "this bug is haunting me lol"
```

**Never Fake Organic:**
```
BAD: [Create fake "player" accounts]
     [Pay people to pretend to be fans]
     [Astroturf positive sentiment]

GOOD: [Amplify real fans]
     [Be transparent about sponsored]
     [Acknowledge criticism openly]
```

### 5.2 Things That Kill Memes

| Killer | Why It Kills | Example |
|--------|--------------|---------|
| Over-explanation | Removes mystery | "For those who don't know..." |
| Corporate adoption | Feels co-opted | Using in official ads |
| Forced variation | Feels desperate | Creating 20 versions |
| Monetization | Feels exploitative | Selling meme merch too fast |
| Age | Natural lifecycle | All memes die eventually |

## 6. Influencer & Creator Integration

### 6.1 Meme Amplification Through Creators

**Tiered Approach:**

| Tier | Followers | Relationship | Meme Role |
|------|-----------|--------------|-----------|
| Nano | 1-10K | Authentic fan | Origin points |
| Micro | 10-100K | Light partnership | Amplification |
| Mid | 100K-1M | Partnership | Legitimization |
| Macro | 1M+ | Strategic | Mainstream crossover |

**Key Principle:** Memes should flow UP, not down
- Organic creates at nano/micro level
- Mid-tier amplifies if authentic
- Macro picks up if genuinely viral
- Never push down from top

### 6.2 Creator Content Strategy

**What We Encourage:**
- Authentic gameplay reactions
- Personal challenge content
- "I played Roanoke for 100 hours" type
- Lore deep-dives
- Community collaborations

**What We Avoid:**
- Scripted "this game is amazing" reads
- Paid meme creation
- Forced enthusiasm
- Obvious brand deals

**Partnership Guidelines:**
- Always disclose sponsorship
- Creative freedom paramount
- Don't script reactions
- Trust creator voice

## 7. Measurement & Analytics

### 7.1 Meme Performance Metrics

| Metric | What It Measures | Target |
|--------|------------------|--------|
| Organic Reach | Non-paid exposure | 10x paid |
| Share Ratio | Shares / Impressions | >1% |
| Sentiment | Positive/Negative | >85% positive |
| Derivative Rate | User variations created | 5x original |
| Longevity | Days meme stays active | 14+ days |
| Cross-Platform | Platforms reached | 3+ |

### 7.2 Warning Signs

**Meme is Working:**
- Strangers using format
- Variations appearing organically
- Press/competitors noticing
- Can't control the narrative

**Meme is Failing:**
- Only our posts get engagement
- Forced variations flop
- Negative sentiment in replies
- Feels corporate in feedback

### 7.3 When to Retire

Signs a meme has peaked:
- Ironic usage ("remember when we said CROATOAN?")
- Competitor co-option
- Cringe factor increasing
- Engagement declining
- We're the only ones posting it

**Retirement Strategy:**
- Gradual reduction, not sudden stop
- Never officially "end" a meme
- Let it fade naturally
- Archive for nostalgia later

## 8. Crisis Management

### 8.1 When Memes Go Wrong

**Scenario: Meme Gets Misinterpreted**
```
Response: Clarify once if needed, then let it go
Never: Double down, argue, or delete
```

**Scenario: Community Creates Problematic Version**
```
Response: Ignore unless harmful
          Address directly if crosses lines
          Don't amplify by over-reacting
```

**Scenario: Competitor Steals Format**
```
Response: Acknowledge humorously if at all
          "Imitation is flattery"
          Never publicly attack
```

**Scenario: Meme Becomes Negative**
```
Response: Self-deprecating acknowledgment
          Fix underlying issue if valid
          Don't suppress organically
```

### 8.2 What We Never Do

- Delete negative memes (unless TOS violation)
- Threaten legal action over parody
- Attack memers directly
- Pretend we don't see criticism
- Take ourselves too seriously
